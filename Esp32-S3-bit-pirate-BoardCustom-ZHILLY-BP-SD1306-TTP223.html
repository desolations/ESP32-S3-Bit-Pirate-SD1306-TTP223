ESP32 Bit Pirate — Board Custom « ZHILLY-BP »

Documentation de référence v1.0 — contribution francophone pour la communauté maker

1. Présentation

Board custom pour le firmware ESP32 Bit Pirate v1.7, fonctionnant sur un ESP32-S3 DevKitC-1 N16R8 avec écran OLED SSD1306 128×64 (I2C) et 3 capteurs tactiles TTP223. Sélection du mode de connexion (WIFI / HOTSPOT / SERIAL) via interface physique, à la manière du T-Embed.

Contribution originale : vue SSD1306 (Ssd1306DeviceView) + input 3 boutons actifs hauts (CustomInput) intégrées au framework du board custom.

5. Build et flash

Prérequis : PlatformIO avec Python 3.10 à 3.13 (pas 3.14 — incompatibilité connue).

pio run -e zhilly-bp                        # build
pio run -e zhilly-bp -t upload --upload-port COMx   # flash
pio device monitor --port COMx             # moniteur 115200
Pièges documentés :
· ImportError littlefs → penv corrompu : supprimer %USERPROFILE%\.platformio\penv puis relancer
· Carte bloquée en waiting for download → maintenir BOOT pendant le lancement du flash
· Toujours lancer PlatformIO depuis le bon Python (3.12) si plusieurs versions cohabitent

7. Le correctif indispensable (piège du framework)

Dans TerminalTypeConfigurator.cpp, le firmware officiel route DEVICE_CUSTOM vers selectHeadless() : sélection automatique après 3 s, seul OK écouté. Retirer DEVICE_CUSTOM du #if pour obtenir le sélecteur interactif ▼▲OK :

// AVANT :
#if defined(DEVICE_M5STAMPS3) || defined(DEVICE_S3DEVKIT) || defined(DEVICE_CUSTOM)
    selected = selector.selectHeadless();

// APRÈS (le correctif) :
#if defined(DEVICE_M5STAMPS3) || defined(DEVICE_S3DEVKIT)
    selected = selector.selectHeadless();

9. Utilisation

  1. Boot → logo « BIT PIRATE » (~1 s)
  2. Sélecteur : ▲ ▼ font défiler WIFI / HOTSPOT / SERIAL — OK valide (aucun timeout)
  3. Première config WiFi : choisir HOTSPOT → rejoindre l'AP depuis un téléphone → http://192.168.4.1 → saisir les identifiants → reboot → mode WIFI → IP affichée → interface web sur téléphone
  4. Mode Serial : terminal PC (115200), taper une touche puis help pour la liste des commandes
